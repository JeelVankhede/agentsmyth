# Plan Architecture Notes

Plan architecture notes preserve implementation-shaping decisions before Build.

Required fields:

- role: `Principal Engineer`
- decisions: phase boundaries, branch strategy, verification strategy, and source handling
- constraints: repo profile, source-of-truth, verification, release, generated output, or protected paths
- tradeoffs: sequencing, risk, ownership, and evidence tradeoffs
- assumptions: assumptions Build, Test, or Ship must preserve or verify
- downstream_impact: review focus, verification evidence, release readiness, or follow-up impact
