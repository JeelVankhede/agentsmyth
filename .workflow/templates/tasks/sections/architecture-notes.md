# Task Architecture Notes

Task architecture notes explain implementation decisions that Review/Test/Ship must understand.

Required fields:

- role: `Senior Engineer`
- decisions: implementation choices made during the active phase
- constraints: plan scope, repo profile, branch policy, generated output, verification config
- tradeoffs: localized alternatives and why one was chosen
- assumptions: assumptions Review, Test, or Ship must verify
- downstream_impact: review focus, verification risk, release readiness, or future maintenance
