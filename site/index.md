## What you actually lose

Most AI coding sessions end the same way. The code exists, the reasoning behind it evaporated the moment the chat scrolled off screen, and the next agent that touches the repo starts cold.

agentsmyth treats that evaporation as the actual problem. Every phase forces the reasoning, the evidence, and the decisions onto disk, where the next request, the next agent, and the next month can read them. Nothing important lives only in the chat, because the chat is the thing that disappears.

It is not a framework, not a linter, not an agent. It is a contract that the agent you already use agrees to follow.
